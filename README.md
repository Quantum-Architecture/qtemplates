# QTemplates — public demos, tests and proofs
**Premium, tested, ready-to-integrate software templates** by Quantum Excellium L.L.C. (brand: Quantum Excellium Marango). This repository holds what a buyer can check **before** buying: live demos, the test report and the sealed package hashes. The templates themselves are licensed per edition at [qtemplates.tech](https://qtemplates.tech).

## Try before you buy (open the HTML files, offline)
| Demo | What it shows |
|---|---|
| `demos/immersive-gallery-demo.html` | a walkable 3D exhibition in one file — the output of the **Immersive Gallery Kit** |
| `demos/premium-demo-page-example.html` | a bilingual product page — the output of the **Premium Demo Page Kit** |
| `demos/qe_preuve.js` | the browser-side journal producer (WebCrypto, zero dependency) used by every demo — the CI runs it and verifies its output with the public verifier |

## Proofs
- `preuves/TEST_REPORT.md` — **55 automated tests across 12 templates, all passing**, regenerated at each release.
- `preuves/PACKAGE_SHA256.txt` — the SHA-256 of every edition package we ship; compare with what you download.
- Every package contains `EDITION.json`, a named `LICENCE_EDITION.txt`, and a `MANIFEST_SHA256.txt` of its own files.
